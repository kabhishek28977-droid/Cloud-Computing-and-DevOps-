# Linux Commands Documentation

## 1. pwd
Shows the current working directory.

Example:
pwd

## 2. ls
Lists files and directories.

Example:
ls

## 3. cd
Changes the current directory.

Example:
cd ~/internship

## 4. cat
Displays file contents.

Example:
cat linux.txt

## 5. touch
Creates an empty file.

Example:
touch notes.txt

## 6. mkdir
Creates a directory.

Example:
mkdir test

## 7. find
Searches for files and directories.

Example:
find . -name "*.txt"

## 8. grep
Searches for text inside files.

Example:
grep "DevOps" notes.txt

## 9. chmod
Changes file permissions.

Example:
chmod 644 linux.txt

## 10. ps
Displays running processes.

Example:
ps

## 11. ping
Tests network connectivity.

Example:
ping -c 4 google.com

## 12. curl
Makes HTTP/HTTPS requests.

Example:
curl -I https://example.com

## 13. git status
Shows the current Git repository status.

Example:
git status

## 14. git log
Shows Git commit history.

Example:
git log --oneline
