# Cloud Computing and DevOps Project Documentation

## Project Overview

This project demonstrates basic Cloud Computing and DevOps practices using Linux, Git, GitHub, networking tools, and Bash automation.

## Technologies Used

- Linux
- Termux
- Git
- GitHub
- SSH
- Bash
- Networking tools

## Project Structure

- `scripts/` - Automation scripts
- `docs/` - Project documentation
- `src/` - Source files
- `README.md` - Project overview
- `.gitignore` - Ignored files

## Networking Tasks

- Ping connectivity testing
- DNS resolution
- HTTP/HTTPS testing using curl
- IP address inspection

## Git and GitHub

Git was used for version control and GitHub was used to store the project remotely.

SSH authentication was configured for secure GitHub access.

## Bash Automation

A Bash script was created to automatically generate the project structure and initialize Git.

## Conclusion

This project provides practical experience with Linux, networking, Git, GitHub, SSH, and DevOps automation.
